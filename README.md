# Football Engine

Um simulador de partidas de futebol simples com sistemas de força em setores de cada equipe, táticas e estatisticas.

<img width="640" height="360" alt="image" src="https://github.com/user-attachments/assets/d619993c-3cc6-49bd-b8b1-8f73d29a41dd" />

## Sobre
Voce poderá fazer simulações entre times fracos e fortes, testar diferentes táticas,  Além de poder escolher qual time está tendo o privilegio de jogar em casa, obviamente afetando nas simulações.

## Lista de funcionalidades
- Atribuição personalizada das seguintes informações de cada time:
  - Nome;
  - Força de ataque;
  - Força do meio-campo;
  - Força da defesa.
- Geração aleatorio da força do time em cada setor.
- Simulações rapidas de uma partida ou 100 de uma só vez.
- Cada equipe pode ter um dia abaixo, normal ou inspirado na simulação.
- Escolha de taticas.
- Escolha de quem jogará em casa.
- Historico de confronto.
- Estatisticas para cada partida.
- Estatisticas All-Time (somatório de todos os dados do confronto).
- Top 3 goleadas do confronto e melhor resultado de cada equipe.
- Reset para o Historico de confronto e das Estatisticas All-Time.
